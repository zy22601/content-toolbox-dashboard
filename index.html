工具 01

R2 图床

拖图 / 粘贴 / 选择图片，传到你的 Cloudflare R2（Worker 图床），返回永久直链、Markdown 和 HTML 片段。密钥只存 Cloudflare 云端，本机浏览器不接触密钥。

图床配置

未配置
托管方式
填你的 Worker 根地址（自定义域名，如 cdn.toolscomb.com），页面自动拼 /upload、/view/<key>
Worker 端 npx wrangler secret put API_KEY 设置后，这里填同一个值；密钥只存 Cloudflare 云端
图片上传后直链形如 <worker>/view/<key>。免 CORS、免本机密钥；上传/删除需上面的 API Key（无 key 无法写入，链接仍公开可访问）。

支持 PNG · JPG · GIF · WebP · SVG

设置

关于这个工作台、快捷键，以及本地运行方式。

快捷键

1–9 切换工具   T 深浅色   Ctrl/Cmd + Enter 当前工具主操作   Ctrl/Cmd + Shift + C 复制当前结果

本地运行

cd ~/workspace/content-toolbox
python3 server.py
# 打开 http://localhost:8080
localhost 是安全上下文：R2 签名、剪贴板复制正常。建议用 localhost 而非 file:// 打开。

AI 选题定位

存本机 localStorage，只在调用本地 DeepSeek 时发送（不经过公开页）。

知识库导出目录

默认指向你的 Obsidian 仓库子目录（/Users/zhangyang/BlinkLLMWiki-Release-v1.0/ContentKB），可改成任意本地目录。

数据存放

R2 密钥、主题偏好存浏览器 localStorage，只在请求时发往 Cloudflare，不经过任何第三方。图片不在本地留副本，上传成功后仅记录直链 URL（可一键清除历史）。
